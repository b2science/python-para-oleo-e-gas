Este notebook demonstra como realizar uma análise exploratória e um controle de qualidade de perfis de poços utilizando ferramentas de visualização e análise descritiva em Python. São utilizadas bibliotecas como Pandas, Matplotlib e Seaborn para investigar a distribuição das variáveis, identificar possíveis valores anômalos (\*outliers\*) e analisar o comportamento dos perfis em relação às diferentes fácies geológicas. O objetivo é mostrar como essas ferramentas podem auxiliar na avaliação da qualidade dos dados, na identificação de padrões e na compreensão das características petrofísicas e geológicas dos intervalos analisados.



Os dados utilizados pertencem a uma competição de machine learning para classificação de fácies, disponibilizada pela Society of Exploration Geophysicists (SEG). O conjunto de dados compreende poços do campo Panoma Council Grove, localizado no sudoeste do Kansas, Estados Unidos, uma região caracterizada pela presença de reservatórios de gás em rochas predominantemente carbonáticas.
