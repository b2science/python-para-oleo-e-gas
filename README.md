Python para Óleo e Gás

Repositório aberto com exemplos e aplicações práticas de Python na indústria de Óleo e Gás, explorando problemas e desafios encontrados no dia a dia de empresas e em estudos técnicos e científicos.

O objetivo é conectar programação, dados e conhecimento de domínio, apresentando aplicações que podem ser reproduzidas e adaptadas utilizando dados públicos e gratuitos.

Os exemplos abrangem diferentes áreas da indústria, incluindo geologia, geofísica, engenharia de reservatórios, petrofísica, produção e ciência de dados, com foco em automação, análise e visualização de dados e desenvolvimento de soluções utilizando Python.

Este repositório também busca servir como material de estudo para geocientistas, engenheiros, estudantes e profissionais de Óleo e Gás interessados em programação e ciência de dados.
